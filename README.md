## Overview

**Nalla-Nudi** is an innovative Android application designed to bridge the language gap for Kannada-medium students transitioning to English in higher education. It serves as a contextual technical dictionary that provides instant access to scientific and mathematical terms in both English and Kannada, with pronunciation guides and flashcard-style revision.

## Problem Statement

Students from Kannada-medium schools often struggle with English technical vocabulary when transitioning to higher education. While they understand the concepts, they face challenges with terminology like "Photosynthesis," "Trigonometry," etc. Standard dictionaries are too broad and lack subject-specific context.

## Features

### 🔍 Smart Search
- **Instantaneous Search**: < 200ms response time
- **Multi-field Search**: Search by English term, subject, or difficulty level
- **Subject Filtering**: Filter terms by Science, Mathematics, or Commerce
- **Offline Support**: 100% offline functionality with pre-loaded database

### 📚 Comprehensive Database
- **Pre-loaded Glossary**: 50+ technical terms across multiple subjects
- **Rich Content**: Each term includes:
  - English definition
  - Kannada translation
  - Pronunciation guide
  - Example usage in English
  - Example usage in Kannada
  - Difficulty level (1-5)
  - Subject classification

### 🎵 Audio Pronunciation
- **Native TTS**: Android Text-to-Speech API integration
- **English Pronunciation**: Hear correct English pronunciation
- **Easy Access**: One-tap pronunciation playback
